# 007-headquarters-cities

Elenca fino a tre sedi principali di un'azienda nella forma Città (Paese), in ordine di importanza, ognuna con una citazione letterale dalle sue pagine.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [007 headquarters cities](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/007-headquarters-cities). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install 007-headquarters-cities@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install 007-headquarters-cities@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Con altri agenti copia la cartella `skills/007-headquarters-cities` tra le skill dell'agente, per esempio in `~/.codex/skills/007-headquarters-cities`.
